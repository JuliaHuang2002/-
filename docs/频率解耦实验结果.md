# MIT 多档采样频率敏感性实验结果

本实验对应开题报告第一阶段的频率解耦任务。输入信号是 MIT SuperCloud 的 `utilization_gpu_pct`（GPU 利用率百分比），不是 `power.draw`。功耗只在后续调度实验中通过功率模型换算。

实验将同一条 1 秒序列以 block-mean 聚合为 1/2/3/5 秒，并固定 lookback=288 点、horizon∈{1,6,36,144} 点。该设计检验的是固定点数预算下的采样频率敏感性；采样间隔变化时，物理回看时长、物理预测时距和有效窗口数也会变化，因此不将结果表述为严格的固定物理时距单因素因果效应。

误差口径与主 benchmark 一致：horizon=h 的 MAE 是每个窗口前 h 个未来点的平均绝对误差。95% CI 使用移动块 bootstrap（block=50 个窗口，2000 次，基础 seed=42，单元 seed=基础 seed+horizon 点数+采样间隔秒数），以保留相邻重叠窗口的局部依赖。nMAE=MAE/std(对应 horizon 真值)。

## 结果摘要

按四步长平均 MAE 的点估计，Chronos-Bolt 在四档采样下均优于持久性基线；其平均 MAE 分别为 1s 的 1.6565、2s 的 1.7713、3s 的 1.7799、5s 的 1.7636，变化并非严格单调。结合置信区间与物理时距变化，本实验支持“模型表现对采样协议敏感”，但不支持“降低采样频率必然改善或恶化预测”的单调结论。
